## 2. 两个值得学的动作：交叉验证 与 推导

### 动作 A：用两套独立口径互相验证
- 海关口径：2024 年中国挖掘机出口 **22.85 万台**。
- 协会口径（主要制造企业统计）：2024 年挖掘机出口 **10.06 万台**（新机）。
- 券商整理海关数据：2024 年**二手**挖掘机出口 **12 万台**。
- 验算：10.06 + 12 ≈ 22.06，与 22.85 万台相差约 0.8 万台（≈3.5%）。
→ 三个来源在误差范围内自洽，**同时反证了"海关总数 = 新机 + 二手"**，
→ 于是可以推出：**二手挖掘机已占中国挖掘机出口台数的约 53%（2024）**。
这一步没有任何单一来源直接说过，是推导出来的；也因此在正文里标了 **[推算]**。

### 动作 B：发现并记录口径冲突，而不是随手挑一个
- 来源 X 说"2024 年我国出口**二手工程机械**约 12 万台，出口额 82.2 亿美元"；
- 来源 Y 说"以挖掘机为例……2024 年达到 12 万台，首次超过新机内需（10.05 万台）和出口（10.06 万台）"。
→ 两个 12 万台，一个说的是**全部二手工程机械**，一个说的是**二手挖掘机**。
→ 处理方式：**保留冲突、标注不确定**，而不是把"82.2 亿美元"当成二手工程机械总额的定论。
（这也是二手设备行业数据的通病：协会、海关、券商、媒体四套口径经常被媒体混用。）

## 3. 可复用 SOP：7 步法

### S1｜先定义"输出物"和"够了"的标准
问自己三句话：这份调研给谁看？要支撑什么决策？看到什么数字就可以停止查？
> 本次：给准备入场的人看；支撑"做不做、做哪个品类、先打哪个市场、怎么起步"；
> 停止条件 = 能给出品类×市场矩阵 + 准入门槛表 + 起步模式 + 单位经济模型。

**反面案例**：不定义停止条件 → 无限查资料、迟迟不做判断。调研是为决策服务的，不是为资料服务的。

### S2｜把大问题拆成 6 个可查证的子问题
| 子问题 | 要拿到的具体答案 |
|---|---|
| 供给 | 国内有多少存量、每年释放多少、货源结构与价格 |
| 需求 | 谁在买、买什么品类、量与增速、价格带 |
| 合规 | 机龄限制、认证、装运前检验、关税税费 |
| 渠道 | 从哪找到买家、成本、周期、谁在做 |
| 经济模型 | 单台成本结构、毛利、周转、资金占用 |
| 风险 | 收款、政策变动、物流、竞争 |

### S3｜来源分层（这是整套方法的核心）
| 层级 | 类型 | 例子 | 可信度 | 用途 |
|---|---|---|---|---|
| **L1** | 官方法规与统计原文 | 海关总署、税务总局、湖南省政府文件、各国部委官网 | 高 | 定门槛、定税率、定政策 |
| **L2** | 行业协会与券商研报 | 中国工程机械工业协会、中国机电产品进出口商会、券商行业深度 | 中高 | 定量、看结构 |
| **L3** | 主流财经/行业媒体 | 新华社系、新浪财经、第一工程机械网、工程机械品牌网 | 中 | 找线索、找 L1/L2 的入口 |
| **L4** | 从业者内容 | 知乎专栏、货代/清关行公众号与网站、外贸 SaaS 博客 | 中低 | 拿操作细节（**必须交叉验证**） |
| **L5** | 卖方营销内容 | 二手设备出口商自己的网站与博客 | 低 | 只用于看"同行怎么说"，**不采信其数字** |

**铁律**：任何写进结论的数字，至少要有一个 L1/L2 来源，或两个独立 L3/L4 来源互证。
只有 L5 支撑的内容，只能写成"业内说法"。

### S4｜检索式模板（可直接套用）
```
① 市场：{品类} 出口 {年份} 主要市场 数据 / {category} export destinations statistics {year}
② 政策：{品类} 出口 政策 {自贸区/试点} 退税 报关 流程
③ 门槛：used {category} import restrictions {country} age limit certification
        + 中文：{国家} 二手设备 进口 机龄 限制 认证
        + 俄文/西语/葡语关键词（对俄、拉美市场很有效）
④ 目的地：{品类} 出口 目的地 排名 {年份} 海关数据
⑤ 单国深挖：{国家} {驱动因素，如"铝土矿"/"2030愿景"} 工程机械 需求
⑥ 渠道：{品类} 出口 怎么找客户 渠道 展会 独立站
⑦ 物流：{品类} 出口 海运 滚装 框架箱 散杂货 运费 港口
⑧ 风控：{品类} 出口 收款 风险 中国信保 信用证 {区域}
```
**技巧**：
- 同一事实至少用**两种语言**各查一次（俄文查报废税、英文查各国准入，信息密度明显更高）；
- 用**具体数字或专有名词**做二次检索（如"утилизационный сбор"、"Permendag 24/2025"、"Decision 18/2019"），能直接跳到原始政策讨论；
- 对每个国家，最后一定要单独查一次"**{国家} + {该国的核心驱动因素}**"，用来验证需求是不是真的（例：几内亚 → 查铝土矿；沙特 → 查 2030 愿景；巴西 → 查矿业与基建投资增速）。

### S5｜校验规则（6 条，逐条过）
1. **三源交叉**：核心数字至少 2 个独立来源，最好 3 个。
2. **口径对齐**：新机会计 vs 二手 vs 合计；台数 vs 金额；协会统计 vs 海关统计；出厂 vs 出口。
3. **时间戳**：每条数据记下发布时间；政策类数据超过 12 个月必须重查。
4. **汇率与单位**：亿元/亿美元、卢布/人民币要换算并注明汇率假设。
5. **识别利益相关方**：卖货的、卖软件的、卖服务的写的"市场分析"，天然会放大机会、淡化门槛。
6. **反例检索**：主动查"这个市场为什么难做 / 失败案例"，只查机会的调研一定是错的。

### S6｜结构化记录（不要只留网页链接）
每查到一个事实就填卡（模板见 §5）。核心是**把"事实"和"判断"分开写**：
- 事实：有来源、有时间、有口径；
- 判断：我的推论，标 **[推算]** 或 **[判断]**，写明依据。

### S7｜出结论时标注置信度，并留一份"未验证清单"
- **H（高）**：L1/L2 原文支撑，或多源一致；
- **M（中）**：L3 多源一致，未及原文；
- **L（低）**：单一 L4/L5 来源，或口径存疑。
未验证清单要写清"要验证什么、去哪验、需要多久"——这比"我说得都对"有用得多。

## 6. 一轮调研的时间与人力预算（一个人）

| 天 | 任务 | 产出 |
|---|---|---|
| D1 上午 | S1 定义 + S2 拆解；确定 3 个候选市场、2 个候选品类 | 一页调研计划 |
| D1 下午 | S3/S4 市场规模 + 品类结构检索（L1/L2 优先） | 数据卡 10–15 张 |
| D2 上午 | 逐国查准入门槛（用英文/当地语言） | 3 张国别档案卡 |
| D2 下午 | 渠道、物流、收款风控 | 渠道对比表、物流方案、风控分级 |
| D3 上午 | 交叉验证 + 反例检索 + 建单位经济模型 | 打分卡 + 单位经济模型 |
| D3 下午 | 写结论、标置信度、列未验证清单 | 调研文档 + 未验证清单 |

**3 天 / 1 人**可以完成"3 个候选市场 + 2 个品类"的完整一轮。要更快就砍市场数量，不要砍验证环节。

## 8. 六个最常见的调研错误（都在这次刻意避开了）

1. **把卖方文章当市场分析**：二手设备出口商的官网博客写"尼日利亚需求旺盛"，是为了卖机器，不是为了告诉你门槛。
2. **混用口径**：新机/二手、台数/金额、协会/海关混着引，是最常见的错误（见 §2 动作 B）。
3. **只看机会不看反例**：不查"俄罗斯为什么难做"就会在 2026 年被 −68.46% 打脸。
4. **忽略时间戳**：政策类信息 12 个月就可能失效（印尼三年改三版）。
5. **用平均值做决策**：非洲"均价高"不等于每个国家都赚钱——几内亚是矿业驱动，尼日利亚是基建 + 外汇风险。
6. **调研完不做决策**：必须有打分卡和"第一步动作"，否则调研只是收藏了一堆链接。
