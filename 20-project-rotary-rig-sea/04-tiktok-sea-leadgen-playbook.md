# 04 · TikTok 东南亚二手机械引流：360° 学习与分析

> 对象：二手旋挖钻机/工程机械，用 TikTok（东南亚）+ 抖音/快手/视频号（国内货源与手法对标）做引流获客。
> 规则：竞品账号与平台数据标来源；手法多为"跨品类迁移"，标 [判断]。

## 1. 一句话结论
**TikTok 在东南亚是"信任型大件"最好的免费曝光场，但不是成交场**——印尼法规禁止社交平台站内成交 [C30][C32]，
恰好逼着我们做对的模型：**TikTok 做内容获线索 → WhatsApp/私域做信任 → 线下验机/试打成交**。
国内抖音/快手二手车、二手设备直播的成熟手法（七天起号、浅层数据、团购、线索表单）可直接迁移，但要把"骗流量"的糟粕去掉 [判断]。

## 4. 我们该怎么做（技巧，按"内容→直播→导流→投放"）

**内容四支柱**（与 GTM 02 阶段 4 对齐，但加本地化）：
1. 试打/试钻视频：钻孔-提钻-甩土全流程，字幕标孔深/孔径/地层（桩基买家只信这个）[判断]；
2. 铭牌+小时数揭表：拍铭牌、拍仪表、拍维保记录——**对治行业"翻新瞒龄"的普遍不信任** [判断]；
3. 整备前后对比 + 央企退场溯源故事（"中国电建项目退场"）；
4. 装柜/绑扎/拆解运输全过程，消除跨境运输恐惧。

**执行细则**：
- 前 3 秒钩子：机器动作（提钻/甩土）+ 大字价格带或机龄（"2019 year, 3,000 hours, full records"）[D18 迁移]；
- 每条 ≤20–30 秒；本地语言字幕优先顺序：英语（菲）→ 印尼语 → 越南语 [判断]；
- 固定时间日更+日播（七天起号法迁移），直播以"现场走场看机+答疑"为主，不憋单不演戏 [判断]；
- 导流：bio + 置顶评论放 WhatsApp/Linktree；**印尼内容只推广不成交，天然合规** [C30]；
- 搜索 SEO：handle 与标题含 "used rotary drilling rig Philippines/Indonesia"、#pilingrig #boredpile 等长尾词 [D19 迁移]；
- 付费：TikTok Ads 线索目标，多计划少预算矩阵；素材复用国内已验证三型 [D18]；
- 矩阵：一国一号一语言，先菲（英）+ 印尼（印尼语）两号，验证后再扩 [判断]。

## 5. 注意事项（做之前必读）
1. **真**：小时数/机龄/库存数字必须与溯源包一致（TRUTH 体系）；不学竞品吹"3,000 台" [判断]；
2. **不站内成交**（印尼）：把"点我买"改成"WhatsApp 看检测报告" [C30][C32]；
3. 认证声明（CE/排放）只有真有才说；
4. 价格内容给"带"不给"点"，避免被锚定与跨市比价 [判断]；
5. 文化：印尼/马来避免不当手势与宗教敏感；周五主麻时间不排直播 [判断]；
6. 首响 SLA ≤5 分钟（与 GTM 一致）；线索 24h 内出方案。
