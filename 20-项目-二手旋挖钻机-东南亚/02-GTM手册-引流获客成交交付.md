# 02 · GTM 手册：引流→获客→成交→交付→复购（二手旋挖钻机×东南亚）

> 框架用 `00-系统/04-通用GTM方法论`；本文件只写"这个品类这个市场"的具体动作。
> 主攻菲律宾、侧翼印尼、机会主义缅甸（见 `01` §4）。

## 阶段 0｜前提（先做，不谈判）
1. **库存三档分级**：按铭牌出厂日期切成 ≤5 / 5–10 / 10–15 / >15 年（`00` §4），每档绑定可进国家；
2. **溯源包**：每台建档案（铭牌照片、小时数、维保/大修记录、原属车队如"中国电建"、权属无抵押证明）——这是相对纯贸易商的第一差异 [判断]；
3. **整备标准**：动力头/主卷扬/履带四轮一带/液压/电气五查，出第三方检测报告；
4. **报价三档**：裸机 / 认证整备机 / 认证+服务包（随机配件+远程支持+3–6 个月关键件保修）。

## 阶段 4｜引流（视频是第一语言）
**内容矩阵（每周 ≥6 条）**：
- 试打视频：现场钻孔、提钻、甩土，带孔深/孔径字幕（桩基买家只信这个）[判断]；
- 小时数/铭牌揭表视频：直接拍铭牌与仪表，做"透明二手机"人设；
- 整备前后对比；装柜/绑扎/拆解运输全过程（降低海外买家对运输损坏的恐惧）；
- 央企退场故事：讲"中国电建项目退场、记录可溯"的货源叙事。

**渠道分工**：
| 渠道 | 市场 | 动作 |
|---|---|---|
| YouTube + Facebook | 菲/印尼 | 试打长视频+短视频，SEO 词 "used rotary drilling rig Philippines/Indonesia" |
| TikTok/抖音 | 引流+国内货源 | 现场实拍，导流私域 |
| WhatsApp/WeChat 私域 | 全部 | 线索沉淀、报价、验机直播 |
| 海关数据+LinkedIn | 印尼/菲 | 筛桩基承包商/租赁公司，定向触达决策人 |
| 中资 EPC 网络 | 全部 | 商会/项目部关系，首单来源 |
| 展会 | 菲(Philconstruct)/印尼(Construction Indonesia) | 展前 60 天邀约，带检测报告 |

## 阶段 5｜成交（带 SLA 的转化链）
```
线索→(≤5min 首响)→合格化(机龄档×国家合规×BANT)→(24h 选型+报价三档)→
视频验机/来华看机/试打→谈判→付款结构→合同+信保→整备排产
```
**付款结构（按 `10-行业/03` §C 分级）**：
- 菲律宾/印尼（黄）：30% T/T + 70% 见提单副本 + 信保；老档/缅甸（红）：100% 前 T/T 或大行保兑即期 L/C；
- 中资项目部：国内/人民币结算，优先做。
**信任物清单**：第三方检测报告、铭牌+小时档案、试打视频、同型号海外交付案例、配件供应承诺。

## 阶段 6｜交付 SOP（写死，逐台执行）
1. 整备+五查+检测报告；2. 目的国检验（柬 PSI、印尼 SNI/许可、越检验证书）[B5][E1]；
3. 拆解：桅杆/钻杆（带杆运输则固定钻杆）/配重分体，重心放低、钢丝绳+链条固定 [D4][D5]；
4. 发运：49 t 级走 FR 或散杂，一案一询价，提前 7–15 天订舱 [D4]；
5. 目的港清关+末端低平板派送（先确认限高限宽）[D6]；
6. **复装+试打+验收+操作手培训**（验收单+客户视频证言入库）；
7. 随机配件包交付（滤芯、油管密封、钻齿、钢丝绳等）。
**首单试单制**：菲律宾先发 1 台验证清关与末端，再放量 [判断]。

## 阶段 7｜复购与转介绍
- 配件先行：常用易损件随柜；在菲建配件合作点（可挂靠本地维修厂）[判断]；
- 回购/置换：给客户"以旧换新"出口回购承诺，把一台做成 2–3 次交易；
- 转介绍返点：老客户介绍成交返配件额度。

## KPI（套 `00-系统/05` §6 基线，逐月校准）
周看：合格线索、首响达标率、报价 turnaround、在途台数、回款达成。
月看：单台毛利、库存周转天、坏账率、退运/索赔率、配件复购率、渠道 CAC。
