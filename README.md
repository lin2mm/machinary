## 当前结论速览（详见各层）
- **二手挖掘机已占中国挖机出口台数约 53%（2024）/ 63%（2025，推算）**；2025 年挖机出口 31.67 万台/107.11 亿美元 [C1]。
- **旋挖钻机东南亚**：主攻菲律宾（无机龄限制）、侧翼印尼（≤10 年）、机会主义缅甸（≤15 年）；马来仅 ≤5 年/项目临时进口 [A8][E15][A9]。
- 决定成败三件事：目的国机龄/认证门槛、收款安全、售后半径。
