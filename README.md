# machinary

二手工程机械从中国出海的调研文档集。

## 三句话结论

1. **市场是真的**：2025 年中国挖掘机出口 31.67 万台 / 107.11 亿美元（同比 +38.6% / +30.8%，海关口径）；按台数推算，**二手挖掘机已占中国挖掘机出口的约 53%（2024）到 63%（2025）**。国内保有量 900 万台以上、每年约 70 万台进入二手流通，供给端不缺货源。
2. **主战场在新兴市场的中大吨位设备**：非洲（2025H1 对非出口 40 亿美元、+51.6%，几内亚 +128.2%）、东南亚（印尼为最大单一市场之一）、中东（沙特 2030 + 迪拜转口）；欧美日澳因 CE / EPA 排放门槛基本进不去，只能吃小挖和配件。
3. **决定成败的不是找客户，是三件事**：目的国机龄与认证门槛（印尼/越南/印度/阿尔及利亚 10 年红线）、收款安全（尼日利亚等国买方违约风险全球前五）、售后半径（配件毛利可达整机 30%–50%，也是复购的来源）。
