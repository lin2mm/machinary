# 04 · 通用 GTM 方法论（高客单 B2B 实物资产版）

> 适用：客单价高（$1万–$100万+）、决策链长、交付重、售后依赖强的实物产品出海。
> 8 个阶段，每个阶段给出"输入→动作→产物→门控（不达标不进入下一阶段）"。

## 阶段 0｜前提三件套（没有就不谈 GTM）
1. **产品/供给画像**：可售清单、分级标准、整备标准、成本线；
2. **合规红线表**：目标市场的准入门槛（把不合规的库存先剔出去，见 `03-合规速查` 类文档）；
3. **单位经济模型**：单台成本→报价→毛利→坏账准备→真实净利；毛利低于警戒线（建议 12%）不做。
门控：三件套齐 + 打分卡 ≥ 试点线。

## 阶段 1｜市场选择（beachhead）
- 用调研方法论 S7 的打分卡给候选市场打分；
- **只选 1 个主攻 + 1 个侧翼**：主攻拿来建体系，侧翼拿来消化不合规/不匹配库存；
- 产物：《市场选择备忘》（1 页，含放弃清单与放弃理由）。

## 阶段 2｜ICP 与客户分层
- 写 3 张 ICP 卡（模板 `05-模板库` §2）：他是谁/他怕什么/他怎么被触达/他的付款习惯；
- 分层：A 类（成交快风险低，如中资海外项目部）→ B 类（客单高壁垒高）→ C 类（量大服务成本高）；
- **先打 A 类建现金流与案例，再攻 B 类建壁垒**。

## 阶段 3｜价值主张与产品化
- 把"卖设备"产品化为三档：**裸机 / 认证整备机 / 认证+服务包（配件+培训+保修期）**；
- 信任物化：第三方检测报告、铭牌/小时数档案、试机视频、同型号海外交付案例；
- 定价：成本线 + 市场带 + 竞品锚，给三档报价（FOB/CIF/DDP 或裸机/整备/服务包）。

## 阶段 4｜渠道与引流（inbound + outbound + partner）
| 类型 | 手段 | 适配 |
|---|---|---|
| inbound | 独立站+SEO、YouTube/TikTok 实拍、B2B 平台 | 长尾、建立信任资产 |
| outbound | 海关数据筛进口商、LinkedIn/WhatsApp 定向、开发信 | 精准大客户 |
| partner | 当地代理/经销商、中资 EPC 网络、展会 | 信任与售后半径 |
- 高客单实物 = **视频是第一语言**：试机、整备前后对比、小时数揭表、装柜绑扎全过程；
- 展会仍是信任建立最快场景，展前 60 天用海关数据邀约。

## 阶段 5｜获客→成交转化链（带 SLA）
```
线索 →(5 分钟内首响)→ 合格化(BANT+机龄合规) →(24h 出选型方案)→
视频验机/来华看机 →(3 工作日报价)→ 谈判+付款结构 → 合同+信保 → 排产整备
```
- 付款结构按国别风险分级（红区 100% 前 T/T 或大行保兑 L/C；黄区 30/70+信保；绿区可账期）；
- 每个阶段有转化率基线，连续 2 周低于基线就回到阶段 3/4 找原因。

## 阶段 6｜交付与履约
- 交付 SOP 写死：整备→检验→拆解/装箱方案→发运→目的港清关→复装→试运行/试打→验收→培训→随机配件；
- **首单试单制**：新市场先发 1 台验证清关与末端派送，再放量；
- 交付完成 ≠ 成交完成：验收单 + 客户视频证言入库，成为阶段 3 的信任物。

## 阶段 7｜售后、复购与转介绍（利润重心）
- 配件先行：常用易损件随柜 + 本地配件合作点；配件毛利常达整机 30–50%；
- 复购闭环：回购/置换/以旧换新，把一台机器做成 2–3 次交易；
- 转介绍机制：老客户介绍成交给返点或配件额度。

## 阶段 8｜组织与本地化（详见各项目的 03-团队文档）
- 三阶段：代理/代表 → 服务点+本地雇员 → 子公司；
- **设点决策门**：年销量、配件收入、服务半径三个阈值，过了才升级形态；
- 先算"本地化成本/单台摊薄"，再决定自建还是挂靠。

## 90 天启动模板
| 周 | 里程碑 |
|---|---|
| 1–2 | 阶段 0 三件套 + 库存分级 + 合规剔除 |
| 3–4 | ICP 卡 + 价值主张 + 报价三档 + 内容素材 20 条 |
| 5–8 | 三渠道并行引流，首响 SLA 跑通，≥30 合格线索 |
| 9–12 | 首单成交+试单发运+验收，复盘转化链，更新打分卡 |

## KPI 树（每周看 5 个，每月看全）
周：合格线索数、首响达标率、报价 turnaround、在途台数、回款达成。
月：单台毛利、库存周转天、坏账率、退运/索赔率、配件复购率、渠道 CAC。
