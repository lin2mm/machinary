# 03 · 通用市场调研方法论（7 步法，行业无关）

> 适用：任何"我要不要把 X 卖到 Y / 进入某市场"的决策型调研。
> 实例：`10-industry-used-machinery/04-research-log-used-machinery.md`、`20-project-rotary-rig-sea/01-market-research-sea-rotary-rig.md`。

## 原则
调研为**决策**服务，不为资料服务。先定义"看到什么就停止"，否则无限查资料、迟迟不判断。

## S1 定义输出物与停止条件
三问：给谁看？支撑什么决策？看到哪些数字就算"够了"？
产物：一页《调研计划》（决策项清单 + 停止条件）。

## S2 拆成 6 个可查证子问题
| 子问题 | 要拿到的答案 |
|---|---|
| 供给 | 存量/货源结构/采购价带 |
| 需求 | 谁买、买什么、量与增速、价格带 |
| 合规 | 准入门槛（机龄/认证/检验/关税/外资持股） |
| 渠道 | 买家在哪里被触达、成本、周期 |
| 经济模型 | 单台/单件成本结构、毛利、周转、资金占用 |
| 风险 | 收款、政策变动、物流、竞争、汇率 |

## S3 来源分层（核心）
按 `02-truth-anti-hallucination` 的 A–E 层。**铁律：写进结论的数字至少 1 个 A/B 或 2 个独立 C/D；E 层只作线索。**

## S4 检索式模板（直接套用）
```
① 规模：{品类} {年份} 市场规模/出口 数据  |  {category} market size statistics {year}
② 政策：{国家} {品类} 进口 机龄/认证/许可 规定  |  {country} import used {category} age limit regulation
③ 原文：找到法令号后二次检索（如 Decision 18/2019、Permendag 24/2025、MITI Heavy Machinery AP）
④ 驱动：{国家} {核心驱动因素} {品类} 需求（几内亚→铝土矿；沙特→2030愿景；菲律宾→Build Better More）
⑤ 价格：used {category} for sale price（E 层样本，只取区间）
⑥ 反例：{国家} {品类} 难做/失败/风险
⑦ 组织：{国家} 外资 设公司 注册资本 持股 限制
```
**技巧**：同一事实两种语言各查一次；用专有名词/法令号跳级到原文；每个国家最后查一次"核心驱动因素"验证需求真伪。

## S5 校验（6 条，逐条过）
三源交叉；口径对齐；时间戳；汇率与单位换算；识别利益相关方；反例检索。
（细则见 `02-truth-anti-hallucination` §3。）

## S6 结构化记录
每查到一个事实填卡（模板见 `05-templates.md`）：**事实与判断分开写**。事实=来源+时间+口径；判断=[推算]/[判断] 并写依据。

## S7 出结论：标置信度 + 留未验证清单
- H = A/B 原文或多源一致；M = 多 C 层一致未及原文；L = 单一 D/E 或口径存疑。
- 未验证清单写清：验什么 / 去哪验 / 工时 / 负责人。
- 用打分卡把调研变成决策（模板见 `05-templates.md` §4）。

## 时间与人力预算（1 人）
| 天 | 任务 | 产出 |
|---|---|---|
| D1 | S1+S2；市场规模与品类结构（A/B 优先） | 调研计划 + 数据卡 10–15 张 |
| D2 | 逐国准入门槛（当地语言）+ 渠道/物流/风控 | 国别卡 3 张 + 风控分级 |
| D3 | 交叉验证 + 反例 + 经济模型 + 写结论 | 打分卡 + 模型 + 未验证清单 |

3 天/1 人 = "3 候选市场 × 2 品类"一轮。要快就砍市场数，不砍验证环节。
